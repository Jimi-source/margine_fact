# Фактическая маржа — веб‑калькулятор

Веб‑интерфейс для расчёта фактической маржи за указанный период на основе
Excel‑отчётов «Начисления», «Заказы», «ПВП», «Трафареты». Расчёты выполняются
локально в браузере.

## Как пользоваться

1. Укажите период (начало/конец).
2. Загрузите «Начисления» за период.
3. Приложение найдёт X — самую раннюю дату в колонке
   «Дата принятия заказа в обработку или оказания услуги».
4. Загрузите «Заказы», «ПВП», «Трафареты» за период X–Y.
5. Нажмите «Рассчитать», результат появится в таблице ниже.

## Себестоимость и вход

Для хранения себестоимости используется Firebase (Google‑вход). После входа
откройте вкладку «Себестоимость», настройте список артикулов и сохраните —
данные будут доступны только вашему аккаунту.

## Примечания

- В «Начислениях» данные начинаются со 2‑й строки (1‑я строка — метаданные).
- В «Начислениях» заполняются A–P, Q–Y рассчитываются.
- В «Заказах» заполняются A–AL, AM–AN рассчитываются.
- В «ПВП» заполняются A–N, O рассчитывается.
- «ПВП» и «Трафареты» учитываются в расчёте, но могут отсутствовать.
